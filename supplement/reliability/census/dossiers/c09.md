# c09 — Electron to Planck mass ratio

```text
name: Electron to Planck mass ratio
definition: Electron rest mass divided by M_Pl = sqrt(ℏ c/G), using the unreduced Planck mass.
dimensions_units: dimensionless
value: 4.1854622191e-23
sigma: 4.7e-28 (G-dominated input propagation)
source: CODATA 2022 adjustment, NIST full numerical table; https://physics.nist.gov/cuu/Constants/Table/allascii.txt; named constants and standard uncertainties
value_confidence: high
```

## Context

The denominator uses ℏ rather than h and includes no factor of 8π. Both this ratio and G m_e²/(ℏ c) use the same mass and gravitational measurements. Squaring the ratio returns that gravitational coupling.
