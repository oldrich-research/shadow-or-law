# c58 — PMNS mixing angles and tribimaximal texture

```text
name: PMNS mixing angles and tribimaximal texture
definition: Bundle three leptonic mixing angles, considered together with the tribimaximal matrix values sin²θ12=1/3, sin²θ23=1/2, sin²θ13=0.
dimensions_units: dimensionless squared sines
value: measured sin²θ12=0.303; sin²θ23=0.572; sin²θ13=0.02203
sigma: +0.012/-0.011; +0.018/-0.023; +0.00056/-0.00059 respectively (1σ)
source: Particle Data Group 2024, neutrino mixing review; https://pdg.lbl.gov/2024/reviews/rpp2024-rev-neutrino-mixing.pdf; Table 14.7 first normal-ordering column; Eq. 14.101 for the xenon-136 bound
value_confidence: high
```

## Context

Solar, reactor, atmospheric and accelerator oscillation results jointly constrain the angles. The quoted normal-ordering fit omits the added SK atmospheric likelihood, as in PDG Table 14.7 first column. The tribimaximal entries are a stated comparison texture, not the fitted values.
