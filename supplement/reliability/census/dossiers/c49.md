# c49 — Chaitin halting probability Ω_U

```text
name: Chaitin halting probability Ω_U
definition: Sum of 2^(-length(p)) over programs p halted by a specified universal prefix-free machine U.
dimensions_units: dimensionless
value: no single decimal supplied: U unspecified
sigma: not applicable
source: G. J. Chaitin, The Limits of Mathematics (1994); https://arxiv.org/abs/chao-dyn/9407003; self-delimiting machine and halting-probability definition
value_confidence: high
```

## Context

A prefix-free program set ensures a probability between zero and one. Different universal machines specify different sums. The definition concerns program execution; it supplies neither a laboratory preparation nor a finite-error measurement procedure for an unspecified U.
