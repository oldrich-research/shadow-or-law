# story

Curated research artifacts; CC-BY-4.0. Source hashes and adaptations: root provenance.json.
Outputs reproduce a constructed programme sample, not a population estimate or proof of ontology.
See root README.md for runnable entry points.

Raw population CSV (`inputs/gfull_engine_exprs.csv.gz`) uses lossless gzip transport; reader checks SHA256 of
decompressed bytes. It and `receipts/population.npz` are the two files over 10 MB listed in the root README: both are
inside `supplement.tar.gz`, not in the companion repository's git tree.

The preregistration is `protocol/PREREGISTRATION.md`. `LEAD_PREREG.md`, the name used for it in
`protocol/LINEUP_PROTOCOL.md`, in `protocol/ADJUDICATION.md` and in the source field of the root `provenance.json`, is its
original file name; those copied documents keep that name unchanged.
